THE CHALLENGE

Make a complex financial journey feel clear and dependable.

The portal supports fund investment, identity onboarding, two-factor authentication, beneficiaries and signatories, deposits, and redemptions. The work translates detailed product rules into a consistent interface and reusable components.

03 / DECISIONS

Choices that make the interface easier to build and use

01 / DECISION

Vanilla CSS & JavaScript

Fits a PHP and Livewire backend without coupling the library to a framework.

02 / DECISION

Tokens as the source of truth

Shared variables keep colors, spacing and states consistent across screens.

03 / DECISION

Clear design authority

Componentes governs visual patterns; Web Mock captures interaction behavior.

04 / DECISION

Name the financial action accurately

“Net divestment for the period” describes withdrawals without labeling them as a loss.

05 / DECISION

One fund state per row

A single status badge reduces competing signals in portfolio lists.

06 / DECISION

Six name fields

Captures the legal names used across Latin American identity documents.

07 / DECISION

Self-hosted Lucide icon font

Keeps the icon set local and available through a predictable class API.

08 / DECISION

AI-assisted, human-reviewed

Claude Code and Codex support implementation; review and CI remain the quality gate.
