EL RETO

Hacer clara y confiable una experiencia financiera compleja.

El portal cubre inversión en fondos, registro de identidad, autenticación de dos factores, beneficiarios y firmantes, depósitos y recompras. El trabajo convierte reglas de producto detalladas en una interfaz consistente y componentes reutilizables.

03 / DECISIONES

Decisiones para facilitar el uso y la implementación

01 / DECISION

CSS y JavaScript vanilla

Se integra con un backend PHP y Livewire sin atar la librería a un framework.

02 / DECISION

Tokens como única fuente de verdad

Las variables compartidas mantienen colores, espaciado y estados consistentes.

03 / DECISION

Autoridad de diseño clara

Componentes rige los patrones visuales; Web Mock documenta el comportamiento.

04 / DECISION

Nombrar bien la acción financiera

“Desinversión neta del periodo” describe retiros sin llamarlos pérdidas.

05 / DECISION

Un solo estado por fondo

Un status-badge reduce señales que compiten en las listas del portafolio.

06 / DECISION

Nombres en seis campos

Registra los nombres legales usados en documentos de identidad de Latinoamérica.

07 / DECISION

Lucide autoalojado como icon font

Mantiene los iconos locales y disponibles con una API de clases predecible.

08 / DECISION

IA asistida y revisada por personas

Claude Code y Codex apoyan la implementación; revisión y CI son el filtro de calidad.
